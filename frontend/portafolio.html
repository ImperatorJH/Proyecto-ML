01 - Proyecto

Un prototipo para automatizar la asistencia academica

El sistema reemplaza el control manual de asistencia mediante reconocimiento facial, registro automatico y visualizacion en un dashboard local.

Problema identificado

El control manual genera demoras en reportes, errores humanos y riesgo de suplantacion de identidad en escenarios academicos.

Solucion propuesta

Capturar video, reconocer estudiantes registrados, almacenar nombre, codigo, fecha y hora, y generar reportes locales.

Alcance

Proyecto academico tipo prototipo funcional, con conjunto limitado de usuarios, ejecucion local y documentacion tecnica.

Valor agregado

Ademas del dataset local, las fotos de registro se respaldan en Cloudinary como evidencia de integracion en la nube.

02 - Objetivos

Objetivos del desarrollo

Cada objetivo se conecta con una parte implementada del sistema: camara, IA, base de datos, frontend y reportes.

Captura en tiempo real

Implementar captura de imagen y video desde la camara del equipo.

Reconocimiento facial

Usar DeepFace y OpenCV para comparar rostros contra el dataset registrado.

Dataset organizado

Crear carpetas por estudiante con fotos y metadatos de nombre/codigo.

Persistencia

Guardar usuarios, fotos y asistencias en MySQL con estructura clara.

Dashboard

Administrar usuarios, consultar asistencias y exportar reportes desde una interfaz web.

Reduccion de errores

Minimizar suplantacion y registros manuales inconsistentes.

04 - Arquitectura

La solucion se divide en captura, reconocimiento, persistencia y presentacion web.
