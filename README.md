# Sistema de Reconocimiento Facial

## Requisitos

- Python 3.11
- Node.js
- MySQL

---

## Instalación Backend

```bash
cd backend
npm install
```

---

## Instalación Python

```bash
cd ML
pip install -r requirements.txt
```

---

## Base de datos

Crear base de datos:

```sql
CREATE DATABASE asistencia_ml;
```

Importar archivo:

```bash
asistencia_ml.sql
```

---

## Ejecutar backend

```bash
node server.js
```
